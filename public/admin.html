🅱️ Binance Pay
When ON, users see 🅱️ Binance (Auto) with Pay ID & QR and can verify via Order ID. Uses BINANCE_PAY_ID/BINANCE_QR_URL/BINANCE_API_KEY env.
🪙 Crypto (OxaPay)
When ON, users see 🪙 Crypto (Auto) — enter USDT, get OxaPay invoice, tap "I Have Paid". Uses OXAPAY_API_KEY (default from bot).
Rate: ₹90 / USDT  •  Min: 0.1 USDT  •  Expiry 30 min • Auto sweep every 60s in bot (website verifies on demand).

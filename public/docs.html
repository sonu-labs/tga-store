TGA Store API

One endpoint, one key. Check live stock and pricing, read your balance, buy a number and fetch its login code — everything over plain HTTPS GET requests.

Keys are tied to your account — the API knows who is calling from the key alone, so you never send a user id. Treat a key like a password: anyone holding it can spend your balance.

available_countries

GET

The full catalogue: every country that currently has stock, with the live selling price in USD. Prices and quantities come straight from the provider, so cache politely and expect them to move.

getNumber

GET

Buys a phone number in the given country. The selling price is deducted from your balance; if the provider fails, the charge is refunded automatically.

getCode

GET

Fetches the login code for a number you bought. Poll every few seconds; until the SMS arrives the API answers with a 409.

ParameterTypeRequiredDescription
actionstringyesgetCode
apiKeystringyesYour key
numberstringyesNumber returned by getNumber

Request

…

Response

{
  "status": "ok",
  "Number": "+6281234567890",
  "code": "47607",
  "pass": "2345GD8R"
}

pass is the account's two-step password (empty when the account has none).

Errors

Failures never return HTML — always JSON, always with a message you can show to a human. 

{
  "status": "error",
  "message": "Insufficient balance. This account costs $0.37."
}
CodeMeaningWhat to do
400Missing or invalid parameterCheck action, apiKey, country_code
401Unknown or revoked keyGenerate a new key above
402Balance too lowTop up the wallet
404Country or number not foundRe-read the country list
409Out of stock, or code not ready yetPick another country / retry shortly
502Provider unavailableRetry with backoff
503Store under maintenanceTry again later

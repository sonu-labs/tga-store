⚙ API Functions
The API exposes these functions: country_info, available_countries, get_balance, getNumber and getCode.
country_info GET
Fetch country information by passing a specific country code, or get every available country by omitting country_code.
ParameterTypeRequiredDescription
apiKeyStringYESYour API key
country_codeStringNoISO country code, e.g. uz

getNumber GET
Purchase a phone number from a specific country. The selling price is deducted from your balance.
ParameterTypeRequiredDescription
apiKeyStringYESYour API key
country_codeStringYESISO country code, e.g. uz
… 
{
  "status": "ok",
  "name": "Uzbekistan 🇺",
  "Number": "+99800000000",
  "price": "0.96",
  "new_balance": "140.50"
}
getCode GET
Get the login code for a number you purchased. Pass the number exactly as it was returned by getNumber.
ParameterTypeRequiredDescription
apiKeyStringYESYour API key
numberStringYESThe purchased number, e.g. +99800000000
… 
{
  "status": "ok",
  "Number": "+99800000000",
  "code": "47607",
  "pass": "2345GD8R"
}
Note: by default, once the login code is received the account password is disabled (2FA removed), so the returned pass lets you sign in directly.

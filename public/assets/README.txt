TGA Store — images folder
=========================

GitHub pe yahan upload karo (same names overwrite kar do):

  public/assets/logo.png      ← TGA Store logo (circle me dikhega)
  public/assets/upi.png       ← UPI photo
  public/assets/binance.png   ← Binance photo
  public/assets/crypto.png    ← Crypto / USDT photo

Kaise:
  1. GitHub repo kholo
  2. public/assets/ folder me jao
  3. Add file → Upload files
  4. Upar wale EXACT names se save karo (logo.png, upi.png, binance.png, crypto.png)
  5. Commit

Website inhe circle me kaategi (square nahi). Light mode me bhi ring ke saath circle dikhega.

PNG / JPG dono chalenge, lekin naam .png hi rakhna.
Best: square photo, 512×512 ya usse badi.
